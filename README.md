# Backend Developer

I'm a backend developer focused on building APIs, data processing systems, and geospatial applications.

I primarily work with Python and FastAPI, using libraries such as Pandas, GeoPandas, and NumPy for data processing and analysis. I also work with C++ and Node.js, with a particular interest in algorithms, performance, and scalable systems.

My main areas of interest are backend development, data processing, geospatial applications, algorithms, and competitive programming.
